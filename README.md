# Wolf Academy India

**Wolf Academy India** is Bangalore's premier combat sports academy, offering training in MMA, Boxing, BJJ, and Muay Thai with National Champions.

## Project Info

- **Website**: [https://wolfacademyindia.com](https://wolfacademyindia.com)
- **Location**: Bangalore, India

## Development

This project is built with:

- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [React](https://react.dev/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Tailwind CSS](https://tailwindcss.com/)

### Getting Started

Prerequisites: Node.js & npm installed.

1.  Clone the repository:
    ```bash
    git clone <YOUR_GIT_URL>
    cd wolf-academy-rising
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```
